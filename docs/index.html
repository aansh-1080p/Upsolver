UPSOLVER V2.0

Official Privacy Policy & Data Transparency Disclosure

EFFECTIVE DATE: AUGUST 2026 · APPLIES TO: UPSOLVER CHROME EXTENSION & WEB PLATFORM

Summary: Upsolver is built on a strict privacy-first architecture. We do NOT collect, sell, or monetize personal identifiable information, passwords, emails, browsing history, or payment data. All competitive programming analysis is performed on public statistics.

1. Information We Process

Upsolver only processes public competitive programming usernames that you explicitly provide:

  • Public Platform Handles: Codeforces handle and LeetCode username entered into the application.
  • Publicly Available CP Statistics: Public contest ratings, rank badges, problem submission timestamps, and tag solve counts retrieved from public Codeforces and LeetCode APIs.

2. What We NEVER Collect (Zero Data Collection)

In accordance with Chrome Web Store User Data Policies, Upsolver explicitly does NOT collect or transmit:

  • No Personally Identifiable Information (PII): No real names, physical addresses, email addresses, phone numbers, or government IDs.
  • No Authentication Credentials: No passwords, session cookies, API secret keys, or authentication tokens.
  • No Web Browsing History: No tracking of websites visited, page navigation, or keystrokes.
  • No Location Data: No GPS coordinates, IP location mapping, or network surveillance.
  • No Financial Data: No payment cards, billing details, or bank account information.

3. Local Storage & Data Retention

All your customized data — including saved study plan checklists, re-attempt flags, friend rosters, and recent handles — is stored locally on your device using the browser's native chrome.storage.local API.

You retain full control over this data and can clear it at any time directly through the extension UI or by clearing extension site data.

4. Permissions Disclosure

  • storage: Required to persist your profile handles, active study plan roadmap, and friend roster locally within your browser.
  • host_permissions: Required exclusively to communicate with the local or cloud Upsolver API server and fetch contest/profile statistics from codeforces.com and leetcode.com.

5. Third-Party Sharing & Monetization

  • We do NOT sell, rent, or monetize user data to third parties, data brokers, or advertising networks.
  • We do NOT use user data for targeted advertising, credit assessment, or personalized marketing.
  • Network communication occurs strictly between your browser and the Upsolver API server for the sole purpose of analyzing competitive programming statistics.
